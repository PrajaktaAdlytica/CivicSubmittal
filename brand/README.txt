CivicSubmittal — Drawing Clasp identity
Selected by the user, 27 October 2026.

CONTENTS
Primary symbol: mark-ink/white/citron/black.svg; mark-reverse.svg is pure white.
Horizontal and stacked logos; wordmarks: four matching colorways.
All lettering is outlined vector geometry from Inter Tight, weight 650.
No external fonts or embedded raster images are required by any SVG.
Micro symbol: mark-micro.svg, optically simplified for small application icons.
Favicon: SVG, ICO (16/32/48), PNG 16/32/48/192/512, Apple touch icon 180.

USAGE
Use ink on paper or citron; use white on charcoal. Preserve aspect ratio.
Clear space: at least one quarter of the primary symbol width on all sides.
Minimum full symbol width: 40px. Below 40px use the micro version.
Minimum horizontal logo width: 190px. Do not rotate, stretch, outline, or add shadows.
Brand colors: ink #232629; paper #fcfbf7; citron #e4f16b; clay #ba4e35.

PRODUCTION
The selected concept silhouette was converted to cleaned Bezier paths with Potrace.
The optical micro-mark is deliberately simplified; it is not a miniaturized illustration.
The font license is included. Design selection does not constitute trademark clearance.
Regenerate lockups and raster icons: npm run brand:build (Node + Python/Pillow).
The original trace can be reproduced with scripts/build-brand.py (Pillow + Potrace).
